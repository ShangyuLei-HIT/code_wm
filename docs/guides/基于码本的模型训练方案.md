\operatorname{MSE}
\left(
\hat z_{t+1},
\operatorname{sg}(z_{t+1}^T)
\right)
]
预测器这里不太对，三个阶段应该和编码器保持统一：
初期：α = 0       全部使用教师码本 latent
过渡：α = 0→1     随机混合教师 latent 和学生 latent
后期：α = 1       全部使用学生编码器生成的 latent
还有就是：三个阶段学习率肯定是越到后面越小的，但是epoch是应该后面越多还是后面越少，因为如果初期：α = 0       全部使用教师码本 latent能用很少的epoch就收敛，更能体现冻结码本训练相较从头训练的优势

实现下面的方案，实现完成后用nohup指令开始训练，训练在GPU1，2，3上进行，三张A100和CPU50个核充分使用，发挥最大速度，并告诉我数据、模型权重、配置文件还有用的各种东西路径都在哪里

核心保持简单：编码器只用连续 latent MSE 和 Soft KL 两项监督；编码器与预测器在同一个训练循环中联合优化；通过三阶段 teacher forcing 从冻结码本 latent 平滑切换到学生连续 latent；训练时不进行在线教师推理。

预测器的输入和预测目标都应使用同一套 teacher-forcing 来源：

\[
h_t=
\begin{cases}
c_{y_t^T}, & \text{使用教师码本}\\
z_t^S, & \text{使用学生编码器}
\end{cases}
\]

预测损失改为：

\[
L_{\mathrm{pred}}
=
\operatorname{MSE}
\left(
F(h_{\le t},a_{\le t}),
h_{t+1}
\right)
\]

阶段一使用教师码本作为输入和目标，因此预测误差不会更新学生编码器；阶段二逐步允许预测误差更新学生；阶段三完全在学生 latent 空间联合微调。

以下是修改后的完整实现方案。

# 1. 总体结构

教师编码器只在训练前离线运行一次。

训练期间：

```text
                         ┌→ 连续 latent MSE
图像 → 学生编码器 → adapter
                         └→ Soft KL

教师缓存 → hard token → 冻结码本查表 → teacher latent
学生编码器                         → student latent

teacher/student latent 按 α 随机选择
                  ↓
          predictor + action
                  ↓
       预测相同来源的下一 latent
```

最终部署：

```text
图像 → 学生编码器 → adapter → predictor
```

不再需要教师、缓存或码本。

# 2. 离线教师缓存

对每个样本和每一帧缓存：

\[
z_t^T=E_T(o_t)
\]

以及：

\[
y_t^T=\arg\min_k\|z_t^T-c_k\|^2
\]

还要缓存距离最近的 top-32 token 及其 soft probability。

目录建议：

```text
.stablewm/distillation_cache/lewm_pusht_seed3072/
├── metadata.json
├── train_teacher_latents.npy
├── val_teacher_latents.npy
├── k512/
│   ├── train_hard_tokens.npy
│   ├── train_topk_indices.npy
│   ├── train_topk_probs.npy
│   └── val_*.npy
├── k2048/
│   └── ...
└── k8192/
    └── ...
```

`metadata.json` 必须包含：

- 教师 checkpoint 和 SHA256；
- 码本 checkpoint 和 SHA256；
- 数据集、split seed 和样本索引；
- normalization、resize、frameskip、num_steps；
- K、latent dimension、top-k、temperature。

训练启动时严格校验，防止缓存与数据错位。

# 3. 学生编码器

学生输出：

\[
z_t^S=A(P(E_S(o_t)))
\]

其中：

- \(E_S\)：新学生编码器；
- \(P\)：projector；
- \(A\)：映射到教师192维空间的 adapter。

adapter 初始实现：

```python
nn.Linear(192, 192, bias=True)
```

使用单位矩阵初始化，bias 为零。

学生模型不再需要：

- decoder；
- reconstruction loss；
- commitment loss；
- hard CE；
- prototype alignment；
- token prior loss。

# 4. 编码器损失

只保留两项。

## 4.1 连续 latent MSE

\[
L_{\mathrm{latent}}
=
\operatorname{MSE}
\left(
z_t^S,
\operatorname{sg}(z_t^T)
\right)
\]

教师 latent 来自缓存，始终不计算梯度。

使用 FP32 计算：

```python
latent_loss = F.mse_loss(
    student_latent.float(),
    teacher_latent.float(),
)
```

## 4.2 Soft KL

学生相对冻结码本的分布：

\[
p_S(k|o_t)
=
\operatorname{softmax}
\left(
-\|z_t^S-c_k\|^2/\tau
\right)
\]

教师 top-32 分布来自缓存：

\[
L_{\mathrm{soft}}
=
\tau^2
\operatorname{KL}(p_T\|p_S)
\]

学生概率必须以全部 K 个 code 为分母归一化；教师只保存 top-32 非零概率。

编码器损失：

\[
L_{\mathrm{encoder}}
=
L_{\mathrm{latent}}
+
\lambda_{\mathrm{soft}}L_{\mathrm{soft}}
\]

默认：

```yaml
loss:
  latent_weight: 1.0
  soft_kl_weight: 0.1
  soft_kl_topk: 32
  temperature: 1.0
```

# 5. 统一的 Teacher forcing

定义教师码本 latent：

\[
q_t^T=c_{y_t^T}
\]

定义学生 latent：

\[
q_t^S=z_t^S
\]

对每条 sequence 采样一个 Bernoulli mask：

\[
m\sim\operatorname{Bernoulli}(\alpha)
\]

然后：

\[
h_t=(1-m)q_t^T+m q_t^S
\]

同一个 sequence 的所有历史帧和预测目标必须使用同一个 mask。

不要每帧独立采样，否则可能出现：

```text
teacher → student → teacher → student
```

这种训练时才存在的混合轨迹。

也不要做线性插值：

\[
(1-\alpha)q_t^T+\alpha q_t^S
\]

因为插值 latent 可能不属于教师或学生的真实分布。

实现方式：

```python
use_student = (
    torch.rand(batch_size, 1, 1, device=device) < alpha
)

mixed_latent = torch.where(
    use_student,
    student_latent,
    teacher_codebook_latent,
)
```

# 6. 修正后的预测损失

预测器的输入和目标都来自 `mixed_latent`：

```python
history_latent = mixed_latent[:, :history_size]
target_latent = mixed_latent[:, prediction_target_slice]

prediction = predictor(
    history_latent,
    action_embedding[:, :history_size],
)
```

损失：

\[
L_{\mathrm{pred}}
=
\operatorname{MSE}
\left(
\hat h_{t+1},
h_{t+1}
\right)
\]

实现：

```python
prediction_loss = F.mse_loss(
    prediction.float(),
    target_latent.float(),
)
```

关键梯度规则：

- 教师码本 latent 本身冻结，不产生梯度；
- 学生 latent 作为 predictor 输入时不能 `detach`；
- 学生 latent 作为 prediction target 时也不能 `detach`；
- 因此 \(\alpha>0\) 后，预测误差通过输入分支和目标分支共同更新学生编码器。

总损失：

\[
L_{\mathrm{total}}
=
\lambda_{\mathrm{pred}}L_{\mathrm{pred}}
+
\lambda_{\mathrm{latent}}L_{\mathrm{latent}}
+
\lambda_{\mathrm{soft}}L_{\mathrm{soft}}
\]

默认：

```yaml
loss:
  prediction_weight: 1.0
  latent_weight: 1.0
  soft_kl_weight: 0.1
```

连续 MSE 和 Soft KL 始终保留，用于阻止后期联合训练重新塌缩。

# 7. 三阶段训练

采用 `4/10/2`，总计16 epochs。

| 阶段 | Epoch | α | Encoder LR | Predictor LR |
|---|---:|---:|---:|---:|
| 教师引导 | 4 | 0 | 1e-3~1e-4 | 1e-3~1e-4 |
| 渐进切换 | 10 | 0→1 | 1e-4~1e-5 | 1e-4~5e-5 |
| 学生微调 | 2 | 1 | 1e-5~1e-6 | 5e-5~5e-6 |

## 阶段一：教师码本引导

```text
Epoch 1–3
α = 0
```

此时：

\[
h_t=q_t^T=c_{y_t^T}
\]

预测损失：

\[
L_{\mathrm{pred}}
=
\operatorname{MSE}
\left(
F(q_{\le t}^T,a_{\le t}),
q_{t+1}^T
\right)
\]

特性：

- predictor 只学习稳定的教师码本 dynamics；
- prediction loss 不影响学生编码器；
- 学生编码器仅由连续 MSE 和 Soft KL 更新；
- 可以验证冻结码本是否显著加快预测器收敛。

## 阶段二：渐进切换

```text
Epoch 4–13
α 按 optimizer step 从 0 线性增加到 1
```

\[
\alpha(s)
=
\frac{s-s_{\mathrm{phase2,start}}}
{s_{\mathrm{phase2,end}}-s_{\mathrm{phase2,start}}}
\]

此时一个 batch 中：

- 一部分 sequence 使用教师码本输入和目标；
- 一部分 sequence 使用学生 latent 输入和目标；
- 使用学生 sequence 的 prediction loss 会更新学生编码器。

随着 \(\alpha\) 增加，学生承担越来越多的 dynamics 建模责任。

## 阶段三：学生独立微调

```text
Epoch 14–15
α = 1
```

此时：

\[
h_t=z_t^S
\]

预测损失：

\[
L_{\mathrm{pred}}
=
\operatorname{MSE}
\left(
F(z_{\le t}^S,a_{\le t}),
z_{t+1}^S
\right)
\]

这一阶段：

- predictor 完全运行在学生 latent 空间；
- prediction loss 完整更新学生编码器；
- 使用很小学习率；
- 只训练2 epochs，防止长时间联合优化导致表示漂移。

# 8. 优化器和学习率

使用一个 AdamW optimizer、两个参数组。

编码器参数组：

```text
student encoder
projector
adapter
```

预测器参数组：

```text
predictor
action encoder
prediction projector
```

公共配置：

```yaml
optimizer:
  type: AdamW
  weight_decay: 1.0e-3

trainer:
  precision: bf16-mixed
  gradient_clip_val: 1.0
  batch_size: 256
  seed: 3072
```

调度：

- 阶段一：5% warm-up，之后 cosine decay；
- 阶段二：切换到更低基础学习率，1% warm-up；
- 阶段三：不 warm-up，低学习率 cosine fine-tune。

阶段切换必须同步更新两个参数组的学习率。

# 10. 阶段切换条件

阶段一结束后，进入阶段二前检查：

- token agreement ≥90%；
- student perplexity / teacher perplexity ≥80%；
- latent MSE 持续下降；
- 未出现单码或少数码塌缩。

如果不满足：

- 保存 checkpoint；
- 停止训练并报告；
- 不进入 teacher-forcing 切换。

最终要求：

- token agreement ≥95%；
- perplexity ratio ≥80%；
- 学生输入预测误差不比教师输入高超过10%；
- 学生 latent effective rank 没有明显下降。

这些只是监控和切换指标，不增加新的 loss。

# 13. 必须测试的行为

1. 训练过程中不实例化教师神经网络；

11. 码本训练前后权重和 SHA256 完全不变；
12. 最终导出模型不包含教师和训练缓存依赖；
13. smoke test 能完整经历 `α=0 → α∈(0,1) → α=1`。

核心训练伪代码：

```python
student_latent = adapter(projector(student_encoder(pixels)))

latent_loss = mse(
    student_latent.float(),
    cached_teacher_latent.float(),
)

soft_kl = compute_soft_kl(
    student_latent,
    frozen_codebook,
    cached_teacher_topk_ids,
    cached_teacher_topk_probs,
)

teacher_latent = frozen_codebook(
    cached_teacher_hard_tokens
)

use_student = (
    torch.rand(batch_size, 1, 1, device=device) < alpha
)

mixed_latent = torch.where(
    use_student,
    student_latent,
    teacher_latent,
)

prediction = predictor(
    mixed_latent[:, :history_size],
    action_embedding[:, :history_size],
)

prediction_target = mixed_latent[:, prediction_target_slice]

prediction_loss = mse(
    prediction.float(),
    prediction_target.float(),
)

loss = (
    prediction_weight * prediction_loss
    + latent_weight * latent_loss
    + soft_kl_weight * soft_kl
)
```

这版方案实现了你要求的梯度控制：

```text
α=0：
prediction loss 不更新编码器

0<α<1：
prediction loss 按学生样本比例逐渐更新编码器

α=1：
prediction loss 完整更新编码器，以小学习率完成最终联合对齐
```
