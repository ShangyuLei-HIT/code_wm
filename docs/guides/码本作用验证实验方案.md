建议把第二项实验设计成“码本质量对照 + 刚体仿射变换对照”两部分。当前只给方案，不修改代码、不启动训练。

已核验：

| 码本 | Shape | 测试集平均绝对 L2 | 测试集平均相对 L2 |
|---|---:|---:|---:|
| K512 | 512×192 | 6.879 | 49.73% |
| K2048 | 2048×192 | 4.419 | 32.04% |
| K8192 | 8192×192 | 2.837 | 20.62% |

三个码本确实构成清晰的质量梯度，适合做该实验。

## 一、实验问题与假设

实验 A：码本质量

在其余条件完全相同时，比较 K512、K2048、K8192 联合蒸馏模型：

- 如果最终 PushT 成功率随 K 增大而提高，说明码本量化质量会传递到模型质量。
- 如果三者实践等价，说明当前联合蒸馏对码本精度不敏感。
- 这里测试的是“当前联合蒸馏方案对码本质量的敏感性”，因为训练仍包含连续 teacher latent MSE，并不是纯离散码本训练。

实验 B：坐标变换不变性

比较原始 K8192 与旋转、平移后的 K8192：

- 码本和所有 teacher latent 同步做同一个刚体仿射变换。
- 码本间距离、局部邻域、token 分配、流形拓扑和形状保持不变。
- 如果模型质量仍有差异，原因将是网络结构、LayerNorm、AdamW、初始化或训练动力学对坐标系敏感，而不是码本流形结构改变。

严格来说，“旋转+平移”是仿射变换，不是纯线性变换。

## 二、核心实验矩阵

| 条件 | 码本 | Latent 坐标 | 用途 |
|---|---:|---|---|
| `k512_original` | K512 | 原始 | 低质量码本 |
| `k2048_original` | K2048 | 原始 | 中等质量码本 |
| `k8192_original` | K8192 | 原始 | 高质量基准，复用已完成实验 |
| `k8192_rigid` | K8192 | 整体旋转+平移 | 流形结构不变实验 |

K8192 seed 3072 已有结果可复用，但会在新的 held-out 测试集上重新评估，以便与其他条件公平配对。

## 三、严格控制变量

所有条件保持以下内容完全相同：

- Teacher checkpoint 和 student 初始化 checkpoint
- 数据集及训练/验证样本索引
- `split_seed=3072`
- 模型结构、参数量和部署结构
- 连续 latent、prediction、soft-KL 三项 loss 权重
- `topk=32`、`temperature=1.0`
- 三阶段 epochs：`[4, 10, 2]`
- 学习率、AdamW、weight decay、gradient clipping
- 每 GPU batch 256，全局 batch 768
- BF16、3 张 A100、50 workers
- Phase 1/2/Final 的评测节点
- 固定的 PushT 起点及 CEM 随机数

K512/K2048 只允许改变：

- `codebook_checkpoint`
- `num_embeddings`
- condition-specific cache/output 路径

原有 Phase 1 gate 将改成“只记录、不提前终止”。否则较差码本可能提前停止，导致各条件训练步数不同，破坏公平性。NaN、文件损坏等硬错误仍立即停止。

## 四、K8192 旋转和平移定义

采用确定性的刚体仿射变换：

\[
T(z)=(z-\mu)Q^\top+\mu+b
\]

其中：

- \(\mu\)：固定训练集 teacher latent 的均值。
- \(Q\)：通过固定 seed 的高斯矩阵 QR 分解生成，并修正到 \(\det(Q)=+1\) 的 192 维正交旋转矩阵。
- \(b=r\,u\)：固定随机方向 \(u\)，平移长度取训练 latent 的 RMS 中心半径 \(r\)。
- 当前抽样估计 \(r\approx13.93\)，实施时会用完整训练缓存精确计算。
- `transform_seed` 固定并写入 manifest，不能根据实验结果调整。

必须同步变换：

1. K8192 的 `teacher.weight` 和 `student.weight`。
2. 训练缓存中的连续 teacher latent。
3. Student adapter 的初始映射。

不能只移动码本而保留 teacher latent 不动；那会改变 latent 与码本的相对关系，不再是“流形结构不变”实验。

为消除额外的初始对齐难度，adapter 将按 \(T\) 初始化，使官方初始化模型一开始就输出变换坐标。Predictor 不做数学上的共轭改写，仍按相同 seed 正常初始化；这样测试的是当前模型和训练流程对坐标系是否敏感。

变换产物将保存：

- 原始和变换后码本 SHA-256
- \(Q,\mu,b\) 和 transform seed
- 正交误差及 determinant
- 逆变换恢复误差
- 随机点对距离误差
- k-NN/token/top-k 一致率
- 协方差谱和 effective rank 对比

验收要求：

- `det(Q)≈+1`
- `QᵀQ≈I`
- 距离最大相对误差低于预设浮点容差
- hard-token 与 top-k 顺序一致率接近 100%
- 码本协方差特征值、effective rank 保持不变

## 五、缓存策略

不会重复运行官方 teacher encoder。

基于现有 K8192 teacher latent 缓存：

- K512、K2048：只重新计算各自的 hard token、top-k indices 和 probabilities。
- K8192 rigid：直接复用原始 K8192 token/top-k，因为刚体变换保持距离；连续 latent 在读取时执行 \(T(z)\)。
- 所有 condition cache 分目录保存，并绑定码本哈希、transform 哈希和样本索引哈希。
- 不覆盖第一项实验的任何文件。

这既减少计算，也确保三个 K 使用逐样本完全相同的 teacher latent。

## 六、训练与 checkpoint 选择

每个条件完整训练 16 epochs，保存：

- Phase 1：epoch 4
- Phase 2：epoch 14
- Final：epoch 16
- 每 epoch 内部指标
- 完整 RNG、cache、codebook 和 transform manifest

为避免用测试集选择模型：

1. 用固定的 50 个 selection 起点评估三个阶段。
2. 按 selection 成功率选择 checkpoint。
3. 平局时依次使用较低的 `pred_mixed_mse`、较早 epoch 作为固定 tie-break。
4. 选定后才在独立的 200 个 held-out 起点上评测一次。

200 个测试任务分成 4×50 批次，避免一次创建 200 个环境造成显存压力。Selection/test 起点写成显式 manifest，保证无重叠并供所有模型复用。

## 七、评测指标

主要指标：

- Held-out PushT 成功率
- 相对 K8192-original 的成功率差
- 逐任务配对成功/失败结果

次要指标：

- Phase 1、Phase 2、Final 成功率和最佳阶段
- latent MSE、soft KL
- Top-1/Top-5 token agreement
- active-code 比例、perplexity/K
- student/teacher effective-rank ratio
- teacher/student rollout prediction MSE
- 训练吞吐、耗时和峰值显存

额外诊断建议：

- 在训练前，用 K512/K2048/K8192 分别做官方模型 encoder-only 和 recurrent 强制量化评测。
- 对 rigid 模型输出执行 \(T^{-1}\)，再比较原始 K8192 模型的 student latent 距离谱、k-NN 图和协方差谱。

## 八、“质量一样”的判定标准

不能因为两次成功率数值相同就直接声明模型一样。

预先定义实践等价区间为 ±5 个百分点：

- 差值的 90% 等价置信区间全部落在 `[-5pp, +5pp]`：判定“实践等价”。
- 置信区间明确越过某一侧且差异检验成立：判定“有显著差异”。
- 其余情况：判定“证据不足”，不能说一样。

统计方法：

- 相同 PushT 起点上的逐任务结果使用配对 bootstrap 和精确 McNemar 检验。
- 多个比较使用 Holm 校正。
- 多训练 seed 时使用分层 bootstrap，同时重采样训练 seed 和评测任务。

## 十、异常后的诊断分支

如果 K8192-rigid 相对原始 K8192 超过 5 个百分点，再补两个 seed3072 诊断条件：

- `k8192_rotation_only`
- `k8192_translation_only`

这样能区分是旋转敏感还是平移敏感。它们不进入首轮核心矩阵，避免无必要增加训练量。
