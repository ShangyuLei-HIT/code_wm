# 离散世界模型：持续学习、自演化词表与多任务词表融合

## 研究动机

当前世界模型相比大语言模型，仍然面临训练不稳定以及难以实现有效扩scaling law的问题。

一个核心原因在于：**复杂物理世界缺少稳定、高质量表征**

大语言模型的成功在于自然语言通过 tokenizer，被映射为有限规模的one-hot向量，从而建立了稳定的表征空间。在这一空间中，模型学习的是明确的输入输出关系和 token 序列之间的统计规律，使得 Transformer 能够通过扩大模型规模和训练数据持续提升性能。

相比之下，物理世界通常表现为连续、高维、多模态的状态空间。当前世界模型大多直接在连续隐空间中学习环境状态变化：

\
z_{t+1}=f(z_t,a_t)

模型泛化能力在于编码器是否能够从数据中提取出跨环境、跨任务稳定存在的潜在结构特征。连续隐空间虽然具有较强的表达能力，但其优化过程更加复杂，容易受到表示漂移、隐空间塌缩等问题影响，使模型难以学习到稳定的高层抽象规律。

因此，本文提出**持续成长的离散世界模型**，希望通过 VQ-VAE 等离散表征学习方法，将连续世界状态映射到结构化的离散隐空间，通过离散词表约束世界模型训练过程，并进一步探索词表的持续学习、自我演化以及多任务融合能力。

# 待研究问题

## 1. 编码器与词表的耦合训练

如何实现 Encoder 与 Codebook 的协同优化，使编码器能够学习有效表征，同时保持词表空间的稳定性，避免二者在训练过程中相互追逐导致表示漂移和训练不稳定。

例如，探索通过 EMA（Exponential Moving Average）等机制实现更加稳定的码本更新。

---

## 2. 持续学习与自演化词表

如何使世界模型的离散表示具备持续学习和自我演化能力，使词表能够随着经验积累不断扩展和重构。

例如，在码本演化过程中，根据 token 之间的关系进行动态调整：相似度不断提高的 token 进行合并，而分布变化较大或表达能力不足的 token 通过细分生成新的表示。

---

## 3. 多任务词表融合

不同任务分别训练得到的离散词表是否能够进行有效融合，并通过词表对齐与模型微调，使单一世界模型能够同时适应多个任务，实现跨任务知识共享与迁移。

---

## 4. 组合式离散表征

如何突破单一离散 token 的表达限制，使编码器能够将复杂状态表示为多个离散 token 的组合，从而提升离散隐空间的表达能力。
进一步研究如何根据输入复杂度动态确定 token 数量，以及多个 token 之间的组合关系。
